# Публикация на GitHub Pages и iPhone

В папке находятся готовые статические файлы. Достаточно GitHub Pages без npm build.

1. На Mac экспортируй прогресс из локального приложения в JSON.
2. В отдельной ветке репозитория добавь файлы этой папки в корень репозитория, затем commit и push. Создай Pull Request и после просмотра объедини его самостоятельно.
3. GitHub → Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Адрес: https://<owner>.github.io/<repo>/ (для обычного репозитория).
5. На iPhone: Safari → открыть сайт → Поделиться → На экран «Домой» → Открывать как веб-приложение → Добавить.
6. Чтобы перенести прошлый прогресс, импортируй ранее экспортированный JSON на новом адресе (по отдельности на каждом устройстве).

Внимание: при отсутствии Supabase прогресс на разных устройствах не синхронизируется.
Публичный сайт содержит URL подключённой Google Таблицы и даёт возможность просматривать её данные, если Google Таблица открыта по ссылке.
