# SpanishApp v0.28.0 — отметки слов

- `✎ Fix me` сохраняет слово для проверки/исправления исходной Google Таблицы. Список находится в разделе «Словарь → Fix me». Ссылка открывает таблицу с диапазоном исходной строки, если она сохранила позицию.
- `↻ Повторить` — независимая отметка для дополнительной практики. Слова доступны в «Словарь → Повторить». По первому открытию приложения с отмеченными словами выбирается отдельный режим «Повторить»; в нём участвуют только отмеченные слова. Можно в любой момент переключиться на «Обычная».
- Повторение списка заканчивается после прохождения слов; «Не знаю» возвращает слово после пяти других ответов (или раньше, если слов меньше). Оценки в этом дополнительном режиме не меняют интервалы обычной тренировки.
- Отметки хранятся локально и экспортируются в JSON; после создания таблицы `word_flags` синхронизируются в Supabase. Доступ пользователей разграничен RLS.

## Перед публикацией

В Supabase SQL Editor выполнить `word-flags-migration.sql`. Этот SQL создаёт только новую таблицу и не меняет `word_progress` и `review_history`.

После публикации проверить отметки на Mac и iPhone, переключение режимов и сохранение через повторный вход.
